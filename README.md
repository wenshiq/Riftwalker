# Riftwalker（暂定名）—— 2D 俯视动作 Roguelite

从零开发的一款 2D 俯视角动作肉鸽（类），作为求职作品集项目。

## 技术栈

- Unity **2023.2.20f1c1**
- 内置渲染管线 + 旧版 Input（零配置，打开就能跑；M4 再考虑切 URP 做辉光/2D 光照）
- 纯 C#，不上重框架（不用 ECS / DOTS）

## 快速开始

1. 打开 Unity Hub → **Add** → **Add project from disk** → 选择本目录（`D:\xinjian\Riftwalker`）
2. 用 **2023.2.20f1c1** 打开，等首次导入完成（自动生成 Library，可能要几分钟）
3. 菜单栏 → **Riftwalker** → **构建 M1 灰盒场景**
4. 点击 **Play** 试玩

## 操作（M1）

| 按键 | 作用 |
| --- | --- |
| WASD | 八向移动 |
| 鼠标 | 瞄准 |
| 按住鼠标左键 | 射击 |
| 空格 | 闪避（带无敌帧） |
