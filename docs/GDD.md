# 游戏设计文档（GDD）

## 基本信息

- **暂定名**：Riftwalker（可改）
- **类型**：2D 俯视角动作 Roguelite
- **平台**：PC
- **单局时长**：8~12 分钟

## 核心体验

「闪避 + 弹幕躲避 + 强化构筑」的爽快动作循环。

## 核心循环

```
进房间 → 打怪 → 打完三选一强化 → 进下一房间 → 打 BOSS → 通关 / 死亡重开
```

## MVP 范围（严格最小，肉鸽最容易膨胀，红线）

- **1 个角色**：移动 + 闪避（无敌帧）+ 射击
- **3~4 种敌人**：近战冲锋、远程射击、自爆、精英
- **1 个 BOSS**
- **房间系统**：房间模板拼接随机（**不做**复杂程序化生成算法）
- **强化**：10~15 项，打完房间三选一
- **UI**：血条、小地图、强化选择、开始 / 死亡 / 通关
- **音效 / BGM**

## 技术栈与约定

| 项 | 选择 |
| --- | --- |
| 引擎 | Unity 2023.2.20f1c1 |
| 渲染 | 内置渲染管线（M4 可切 URP） |
| 输入 | 旧版 Input（M2 后可切 Input System） |
| 移动 | `Rigidbody2D.MovePosition` |
| 伤害 | 触发器 + `IDamageable` 接口 |
| 数据 | `ScriptableObject` 数据驱动（M2 起） |
| 架构 | 单例 + 状态机 + 事件总线（逐步引入） |
| 对象池 | 子弹 / 敌人（M2 起） |
| 编码 | UTF-8，按功能分目录 |

## 目录结构

```
Assets/Scripts/
  Core/        接口、工具、占位美术
  Player/      玩家
  Enemies/     敌人
  Combat/      战斗（子弹等）
  Camera/      相机
  UI/          UI（M3 起）
  Data/        ScriptableObject 数据（M2 起）
Assets/Editor/ 编辑器工具（场景一键构建等）
```

## 开发顺序（先灰盒后美术，红线）

```
M1 灰盒 → M2 循环 → M3 闭环 → M4 美术打磨 → M5 作品集
```

> 学生项目最常见的死法是"先画一堆美术、代码一行没动"。本项目反过来：先用色块把玩法 / 手感调爽，再换正式素材。
